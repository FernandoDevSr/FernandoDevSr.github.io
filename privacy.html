Política de privacidad

Radio México de Siempre

Responsable: FA APP STUDIO
Contacto: faappstudio@gmail.com
Última actualización: 5 de octubre de 2026

1. Alcance

Esta política explica cómo Radio México de Siempre trata información cuando utilizas la aplicación. La aplicación no requiere crear una cuenta y FA APP STUDIO no opera un servidor propio para almacenar perfiles personales, historial de escucha o ubicación del usuario.

2. Reproducción de radio

La aplicación se conecta a servidores de emisoras de terceros para reproducir audio. Esos servidores pueden recibir información técnica necesaria para entregar la transmisión, como la dirección IP y datos de conexión. FA APP STUDIO no controla las prácticas de privacidad de cada emisora.

La aplicación también descarga un catálogo público de emisoras desde infraestructura web de FA APP STUDIO. Esta descarga no requiere cuenta ni perfil de usuario.

3. Publicidad

La edición pública utiliza Google Mobile Ads para mostrar publicidad y Google User Messaging Platform (UMP) para gestionar consentimiento y opciones de privacidad cuando corresponde.

Estos servicios de Google pueden tratar información técnica y de uso, como dirección IP, interacciones con la aplicación, información de diagnóstico e identificadores del dispositivo o de la cuenta, para finalidades como entrega y medición de publicidad, seguridad y prevención del fraude. El tratamiento concreto depende de la región, el consentimiento y la configuración publicitaria.

4. Diagnóstico de estabilidad

La edición pública utiliza Firebase Crashlytics para detectar y diagnosticar cierres inesperados, errores y ANR. Esta versión no utiliza Firebase Analytics ni Firebase Performance Monitoring.

Crashlytics puede tratar información técnica asociada a un fallo, como stack traces, estado relevante de la aplicación, metadatos del dispositivo y un identificador de instalación.

Radio México de Siempre puede adjuntar datos técnicos no personales para diagnosticar reproducción, como razón interna de fallo, ID técnico de emisora, índice del stream, tipo general de red, tiempo de inicio del audio y contador de buffering. La aplicación no agrega URLs de stream, nombres, correos, teléfonos, ubicación precisa ni otros identificadores personales definidos por el desarrollador.

5. Preferencias guardadas en el dispositivo

La aplicación puede guardar localmente la emisora seleccionada, emisoras favoritas, estado de reproducción, una copia válida del catálogo de emisoras e información técnica utilizada para mejorar el cambio entre señales. Estas preferencias no se envían a servidores propios de FA APP STUDIO como perfil de usuario.

6. Datos que la aplicación no solicita

La aplicación no solicita acceso a ubicación, contactos, cámara, micrófono, SMS, historial de llamadas, archivos personales ni credenciales del usuario. En versiones recientes de Android puede solicitar permiso de notificaciones para mostrar controles de reproducción.

7. Conservación y eliminación

Las preferencias locales se conservan mientras la aplicación permanezca instalada o hasta que el usuario borre los datos de la aplicación desde Android. Al desinstalar la aplicación, Android elimina esos datos locales.

FA APP STUDIO no mantiene una cuenta de usuario ni una base de datos propia con perfiles personales de los usuarios de Radio México de Siempre. Los datos técnicos tratados por Google Mobile Ads, UMP y Firebase Crashlytics se conservan y eliminan conforme a las políticas y controles de Google aplicables a esos servicios.

Para consultas de privacidad o solicitudes relacionadas con datos bajo control de FA APP STUDIO, puedes escribir a faappstudio@gmail.com.

8. Seguridad

Las conexiones con los servicios de Google utilizados por la aplicación se realizan mediante conexiones cifradas en tránsito. La aplicación limita sus permisos y no solicita datos personales que no sean necesarios para su funcionamiento.

9. Opciones de privacidad

Cuando la normativa o la configuración publicitaria lo requieren, la aplicación ofrece opciones de privacidad gestionadas mediante Google UMP. Estas opciones pueden permitir revisar o modificar decisiones de consentimiento relacionadas con publicidad.

10. Terceros

Los principales terceros integrados en la edición pública son Google Mobile Ads, Google User Messaging Platform y Firebase Crashlytics, todos proporcionados por Google. Además, la aplicación se conecta directamente a los servidores de las emisoras seleccionadas para reproducir audio.

11. Cambios a esta política

Esta política puede actualizarse cuando cambien las funciones de la aplicación, los servicios utilizados o los requisitos aplicables. La versión vigente se publicará en esta página junto con su fecha de actualización.
